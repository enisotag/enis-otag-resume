01 · YAPAY ZEKÂ & AJANLAR

Borsa Ajanı (v2.0)

BIST Yapay Zekâ Analisti & Portföy Telegram Ajanı

Kas 2026 – Günümüz · Python · Docker

Borsa İstanbul (BIST) piyasalarını izleyen, eş zamanlı çok kaynaklı veri toplama ve yapay zekâ sentezini Telegram arayüzünde birleştiren otonom finansal analiz ve portföy ajanı. TradingView Scanner API, Yahoo Finance, Google News RSS ve aracı kurum hedef fiyat akışları; ThreadPoolExecutor eş zamanlı iş parçacığı havuzu ve TTL önbellekleme katmanı üzerinden tek bir analiz hattında birleştirilir.

Çıkarım katmanında birincil olarak Google Gemini API kullanılırken yüksek erişilebilirlik için otomatik Groq / Llama 3.3 yedek yönlendirmesi devreye girer. Aracı kurum portföy ekran görüntülerinden Vision OCR ile varlık ayrıştırma, /firsatlar (%35 üzeri getiri potansiyeli ve ≥2 AL tavsiyesi filtresi), /altinhisseler, /temettu ve /kiyasla komutları; sunucusuz ortamlar için headless Matplotlib koyu tema grafikleri, SQLite kalıcılığı, GitHub Contents API yedeklemesi ve tam Docker konteynerizasyonu ile sunulur.

Autonomous Borsa İstanbul (BIST) equity analyst and personal portfolio Telegram agent built on a concurrent multi-source ingestion pipeline. Data from the TradingView Scanner API, Yahoo Finance, Google News RSS, and brokerage target-price feeds is aggregated in parallel via ThreadPoolExecutor with a deterministic TTL cache layer.

LLM reasoning routes primarily through the Google Gemini API with automatic fallback to Groq / Llama 3.3 for resiliency. Core capabilities include Vision OCR parsing from broker portfolio screenshots, algorithmic screening commands (/firsatlar requiring >35% upside and ≥2 BUY ratings, /altinhisseler, /temettu, /kiyasla), headless Matplotlib dark-mode chart rendering, SQLite persistence paired with automated GitHub Contents API backups, and Dockerized deployment.

  • LLM & Yedekleme Google Gemini API birincil çıkarım + Groq / Llama 3.3 otomatik yedek katmanı
  • Görsel OCR & Grafikler Portföy ekran görüntüsü Vision OCR + headless Matplotlib koyu tema grafikleri
  • Komutlar & Kalıcılık /firsatlar (>35% potansiyel, ≥2 AL), /altinhisseler, /temettu, /kiyasla · SQLite + GitHub Contents API · Docker

02 · YAPAY ZEKÂ & AJANLAR · INTERTECH

VIRA Finance Agent

Çok Ajanlı Yapay Zekâ Finansal Asistanı

Ağu 2026 – Eyl 2026 · Intertech ile İlişkili

Intertech bünyesindeki 30 iş günlük mühendislik stajı kapsamında kurgulanan çok ajanlı finansal yapay zekâ asistanı. LangGraph ve LangChain üzerinde çalışan durum grafiği mimarisi; AnalystAgent ve uzman alt modüller arasında görev dağılımını deterministik biçimde yönetir.

Retrieval-Augmented Generation (RAG) katmanı ile gerçek zamanlı finansal metrik araç çağrıları birleştirilerek LLM yanıtları doğrulanabilir kurum verilerine dayandırılır. Kural tabanlı kapsam doğrulama mekanizması alan dışı istekleri erken aşamada engellerken, uçtan uca izleme altyapısı her ajan geçişini ve araç çağrısını kayıt altına alır.

Multi-agent AI financial assistant developed in association with INTERTECH during an intensive engineering cycle. Built on LangGraph and LangChain state-graph orchestration, it coordinates AnalystAgent alongside specialized reasoning modules to decompose complex financial workflows.

The system integrates Retrieval-Augmented Generation (RAG) with dynamic tool-calling grounded directly in real-time financial metrics. A rule-based scope validation layer enforces strict domain guardrails before execution, complemented by end-to-end monitoring across agent transitions and retrieval latency.

03 · SİSTEM & AĞ PROGRAMLAMA

Winsock HTTP/1.1 Socket Server in C

C ile Çerçevesiz TCP/IP Soket Sunucusu

2026 · C · Windows Winsock API

Harici hiçbir web çerçevesi veya yüksek seviyeli ağ kütüphanesi kullanmadan doğrudan Windows Winsock API üzerinde C diliyle geliştirilen düşük seviyeli TCP/IP HTTP/1.1 sunucusu. Sunucu, localhost:8080 adresinde ham dinleme soketi açarak işletim sistemi ağ yığınıyla doğrudan iletişim kurar.

İstemciden gelen TCP bayt akışı doğrudan ayrıştırılarak ham HTTP istek satırı ve başlık yapısı çözümlenir; ardından standartlara uygun HTTP/1.1 200 OK yanıt paketleri üretilir. Soket başlatma, bağlama, kabul, okuma/yazma ve kaynak serbest bırakma adımları sıralı ve deterministik bir bağlantı yaşam döngüsüyle yönetilir.

Low-level TCP/IP HTTP/1.1 server written from scratch in C on top of the native Windows Winsock API with zero external frameworks or HTTP abstractions. It binds a listening socket directly to localhost:8080 to interface with the OS networking stack at the transport boundary.

Incoming byte streams are read directly from socket buffers for raw HTTP request parsing, followed by compliant HTTP/1.1 200 OK response construction and transmission. Every connection moves through an explicit, sequential lifecycle covering socket initialization, binding, accept, I/O framing, and clean teardown.

MİMARİ BİLEŞENLER & TEKNİK ÖZELLİKLER

  • Taşıma Katmanı Windows Winsock API ile çerçevesiz TCP/IP dinleyicisi (localhost:8080)
  • Ham İstek Ayrıştırma Soket alma tamponlarından doğrudan HTTP/1.1 istek satırı ve başlık okuma
  • Yanıt Üretimi Sıfır bağımlılıkla geçerli HTTP/1.1 200 OK başlık ve gövde sentezi
  • Bağlantı Döngüsü Deterministik sıralı kabul, veri aktarımı ve güvenli soket kapatma

04 · WEB & İNTERAKTİF · VERİTABANI

Advanced Native PHP & MySQL CMS

Sıfırdan Geliştirilmiş İlişkisel İçerik Yönetim Sistemi

2026 · PHP · MySQL · PDO

Harici framework veya ORM bağımlılığı olmadan saf PHP ve MySQL üzerinde sıfırdan tasarlanan tam yığın içerik yönetim sistemi. Tüm veritabanı işlemleri parametreli PDO Prepared Statements üzerinden yürütülerek SQL Injection saldırı yüzeyi bütünüyle ortadan kaldırılır.

Yönetim paneli güvenliği bcrypt algoritmalı password_hash() parola doğrulaması ve oturum tabanlı yönetici güvenlik duvarıyla sağlanır. Veritabanı katmanında Kategoriler–Yazılar arasında 1:N, Yazılar–Etiketler arasında ise ara tabloyla N:M ilişkisel şema kurulmuş; ön yüzde ise arama motoru dostu (SEO) temiz bir yayın mimarisi uygulanmıştır.

Custom Content Management System built from scratch in native PHP and MySQL without external frameworks or third-party ORMs. Every database operation executes through parameterized PDO Prepared Statements to enforce strict SQL injection protection across read and write paths.

Administrative access is protected with bcrypt password_hash() authentication and a session-based admin firewall. The relational MySQL schema cleanly models 1:N Categories-to-Posts and N:M Posts-to-Tags associations, paired with a lightweight, SEO-friendly public frontend.

MİMARİ BİLEŞENLER & TEKNİK ÖZELLİKLER

  • SQLi Koruması Tüm veri katmanında parametreli PDO Prepared Statements kullanımı
  • Kimlik & Güvenlik Duvarı bcrypt password_hash() parola güvenliği + oturum tabanlı yönetici duvarı
  • İlişkisel Şema 1:N Kategoriler–Yazılar ve N:M Yazılar–Etiketler normalleştirilmiş tabloları
  • SEO Ön Yüz Harici framework olmadan semantik yapı ve SEO uyumlu yayın katmanı

05 · WEB & İNTERAKTİF · HTML5 CANVAS

Enis's Career Journey

Etkileşimli 2D Piksel Platform Kariyer Oyunu

HTML5 Canvas · 3 Bölüm + Sonsuz Mod

HTML5 Canvas ve saf JavaScript ile piksel sanat estetiğinde geliştirilmiş, bu portfolyoya özel 16:9 gömülü bir sahne olarak entegre edilen etkileşimli 2D yatay ilerlemeli (side-scroller) platform oyunu.

Oyuncular üç kariyer durağını delta-time ile dengelenmiş akıcı tempo ve çift zıplama mekanikleriyle deneyimler: Eskişehir Fatih Fen Lisesi & YKS 457.’si Boss Savaşı ile başlar, İTÜ & BİDB kampüs operasyonlarından geçer ve Intertech Stajı aşamasıyla tamamlanır. Ardından yüksek skor hedefli Sonsuz Mod (Endless Mode) açılır; oyun arayüzü Türkçe, İngilizce, Arapça, İspanyolca ve Japonca olmak üzere 5 dili destekler.

Interactive 2D side-scroller built in HTML5 Canvas and vanilla JavaScript with custom pixel-art sprites, seamlessly integrated into this portfolio inside a dedicated 16:9 embedded game stage.

Driven by delta-time paced movement and responsive double-jump physics, the game guides players across three playable career milestones—Eskişehir Fatih Fen Lisesi & the YKS 457th Boss → İTÜ & BİDB → Intertech Internship—before unlocking a high-score Endless Mode with 5-language localization (TR, EN, AR, ES, JA).
